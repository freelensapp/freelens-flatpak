Automated updates of the Flathub package of
[Freelens](https://github.com/freelensapp/freelens).

The updates, with the summary of the release notes, are generated here and
submitted to
[flathub/app.freelens.Freelens](https://github.com/flathub/app.freelens.Freelens)
through the fork
[freelensapp/app.freelens.Freelens](https://github.com/freelensapp/app.freelens.Freelens).

Install:

```sh
flatpak install flathub app.freelens.Freelens
```

See: <https://flathub.org/apps/app.freelens.Freelens>
